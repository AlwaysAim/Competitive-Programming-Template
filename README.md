# 算法竞赛板子

我自己的算法竞赛速查本。LaTeX 写的，两栏窄边距，打印出来能直接带进考场翻。

里面有：

- **板子**：常用数据结构、图论算法的可复用代码
- **trick**：各种题里的套路和小技巧
- **心得**：做题时踩过的坑、想明白的道理、容易被忽略的细节，也顺手记了 C++ 语法上的一些坑

目前按「杂项 / 数据结构 / 图论 / 语法注意事项」分章，以后做到新东西继续往里加。

## 编译

用 XeLaTeX（用了 ctex 和系统字体），跑两遍出目录：

```bash
xelatex main.tex
xelatex main.tex
```

VS Code + LaTeX Workshop 直接 `Ctrl+Alt+B`。改了内容双击 `push.bat` 就会自动编译并推到这个仓库。
